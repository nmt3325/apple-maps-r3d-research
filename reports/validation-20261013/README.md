# Independent numeric decoder evidence — 2026-10-13 UTC

The reports here were generated by the current independent Python implementation on Linux, using original R3D input. Saved native arrays are used only in the Tokyo comparators. The Oahu decoder receives only original R3D.

- `splat-arrays.json` / `.log`: all 223 Tokyo tiles, full 3*N XYZ vertices, eight attributes including canonical NaNs, and complete material20 byte arrays. Zero bit/byte mismatches.
- `mesh-arrays.json` / `.log`: all 223 Tokyo tiles, six original polygon arrays and primary HEIC. XYZ, UV, all indices and all 223 images are exact. All 271 normal Y differences are individually explained by 90-digit Decimal sine/cosine and adjacent native float32 sine rounding. Maximum 1 ULP, absolute 5.960464477539063e-8.
- `oahu-decoded.json` / `.log`: 72 original Oahu tiles, 304,527 Splat records, 581,186 original polygon triangles. Every tile passes geometry finite-value, array shape, index, UV and normal-length checks. 4,137 RGB components are canonical missing-value NaNs, preserved in raw attributes and packed to zero for rendering.
- `oahu-soup-geography.json`: every decoded Splat vertex transformed by the original tile matrix/translation and checked geographically in Oahu. Per-tile bounds are included. This checks soup geography; polygon/Splat display and alignment remain to be verified together.
- `numeric-tests.log`: eight focused regression tests, including an original numeric fixture and corrupt-input rejection.
- `frame-tests.log`: 295 original frames, 590 lane directories, 885 original HEIC payloads, and three malformed/truncated inputs.

Each full array report includes per-tile original SHA-256, array SHA-256, counts, differences, actual command and implementation file hashes. See [the decoder specification](../../docs/INDEPENDENT_DECODER.md) for portable reproduction commands and exact output layouts. Original/golden input archives remain attached to private Release `snapshot-20261014`.

These are numerical decoder results. The complete arbitrary-coordinate fetch → hybrid viewer workflow is still unfinished, and the main goal remains active. Official pixel parity, exact LOD and native accumulation/color transfer are separately unfulfilled additional goals.
